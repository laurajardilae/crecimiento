# Crecimiento técnico

Repositorio personal donde organizo y documento los conceptos técnicos que voy repasando para crecer profesionalmente. Cada tema tiene un resumen con mis propias palabras, ejemplos y la fecha de repaso, de modo que el historial de commits sirve como bitácora de aprendizaje.

## Cómo está organizado

- [`PROGRESO.md`](PROGRESO.md): tabla con los objetivos, su estado y enlaces a las notas.
- [`conceptos/`](conceptos): una carpeta por tema, con su resumen y ejemplos.
- [`plantillas/`](plantillas): plantilla base para cada concepto nuevo.

## Cómo agrego un tema

1. Copiar `plantillas/concepto.md` a `conceptos/<tema>/README.md`.
2. Completar el resumen y agregar ejemplos en `conceptos/<tema>/ejemplos/`.
3. Registrar el tema en `PROGRESO.md`.
4. Hacer un commit pequeño, por ejemplo: `docs(<tema>): repaso de <concepto>`.
